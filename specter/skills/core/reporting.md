# Reporting Skill

Organizes penetration testing results into a structured report containing detailed findings, PoC scripts, and remediation recommendations.

## Report Structure

### 1. Project Overview
- Test targets
- Test timeframe
- Test scope
- Test methodology

### 2. Executive Summary
- Overview of high-risk findings
- Risk severity distribution
- Key recommendations

### 3. Detailed Findings
For each vulnerability:
- Vulnerability name and severity level
- Vulnerability type
- Impact scope
- Verification steps
- Key evidence (requests/responses/screenshots)
- PoC script
- Remediation recommendations

### 4. Attack Path
- Full attack chain diagram
- Path from initial access to final objective

### 5. Appendices
- PoC scripts
- Traffic captures
- Screenshot evidence
